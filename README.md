# 유약 노트 釉藥

도자기 유약 레시피 25종을 소성 조건과 원료 조성으로 정리한 한 장짜리 웹 페이지입니다.
청자유·천목유 같은 고화도 유약부터 라쿠·저화도 유백유까지, 배합비를 만들 양에 맞춰
그램 단위로 바로 환산해 볼 수 있습니다.

## 실행

빌드 도구도 설치 과정도 없습니다. `index.html`을 브라우저로 열면 끝입니다.

```bash
open index.html
```

## 기능

- **계량 환산** — 상단 `만들 양`에 그램 수를 넣으면 모든 레시피의 계량 값이 함께 바뀝니다. 기본값은 1,000g입니다.
- **필터** — 소성 분위기(산화·환원), 표면(투명·유탁·무광·빙렬·결정), 온도대(고화도·저화도)로 추려 봅니다.
- **시편 그림** — 사진이 없는 유약은 레시피 이름을 씨앗 삼아 만든 SVG 시편 그림이 대신 들어갑니다. 같은 유약은 언제나 같은 무늬로 그려집니다.
- **소성 메모** — 레시피마다 직접 구워 본 결과를 남길 수 있습니다. 메모는 브라우저의 `localStorage`에만 저장되므로 다른 기기에서는 보이지 않습니다.
- **안전 표시** — 식기 내면 주의, 환기 필수, 알칼리 주의처럼 원료를 다룰 때 필요한 경고가 레시피별로 붙습니다.

## 사진 넣기

`index.html` 옆에 `images` 폴더를 만들어 사진을 넣고, 파일 안의 `PHOTOS` 목록에 파일명을 적으면
색 타일 자리에 사진이 들어갑니다.

```js
const PHOTOS = {
  celadon: { src: "images/celadon.jpg", credit: "" },
  ...
};
```

`src`를 비워 두거나 파일을 찾지 못하면 원래의 SVG 시편 그림이 그대로 보입니다.
`credit`에는 사진 출처를 적고, 직접 찍은 시편이면 비워 둡니다.

## 안전

유약 원료 중에는 몸에 해로운 것이 있습니다. 페이지 상단의 `원료를 다룰 때` 항목을 먼저 읽어 주세요.
특히 규석 분진은 방진 마스크 없이 다루지 않고, 탄산바륨·구리·크롬·코발트·망간·니켈이 든 유약은
식기 안쪽 면에 쓰지 않습니다.

## 결과를 읽을 때

같은 레시피라도 가마, 소지, 시유 두께에 따라 결과가 달라집니다.
본 소성 전에 반드시 시편을 구워 보세요. 표기된 온도는 목표 온도이며,
실제로는 콘이 쓰러지는 시점을 기준으로 판단합니다.

## 구조

```
.
├── index.html      # 페이지 전체 (마크업·스타일·레시피 데이터·스크립트)
└── README.md
```

레시피 데이터는 `index.html` 안의 `RECIPES` 배열에 있습니다. 항목을 추가하려면
`id`, `name`, `atmos`, `temp`, `surface`, `base`, `add`, `note`를 채워 넣으면 됩니다.
